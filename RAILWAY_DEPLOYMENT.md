# Развертывание Telegram-бота на платформе Railway.app

[Railway](https://railway.app/) — это одна из лучших и самых простых платформ для хостинга Python-ботов и баз данных PostgreSQL. Она автоматически собирает ваш код прямо из GitHub-репозитория и перезапускает сервер при каждом новом коммите.

Ниже приведена пошаговая инструкция по деплою бота `TelegaAutoPublishNEWS`.

---

## Шаг 1: Подготовка кода и загрузка на GitHub

Railway берет код напрямую из вашего GitHub-репозитория. 
Убедитесь, что ваш проект лежит на GitHub и в корне репозитория есть все необходимые файлы:
1. `app.py` — главный файл запуска.
2. `requirements.txt` — список библиотек.
3. `.gitignore` — файл, в котором скрыт `.env` (никогда не загружайте `.env` в публичный репозиторий!).
4. Файл `Procfile` (создайте его в корневой папке проекта без расширений) со следующим содержимым:
   ```text
   worker: python app.py
   ```
   *(Здесь `worker:` означает запуск фонового процесса, так как ботам не требуется выделять публичный веб-порт в режиме Polling. Для Webhook-режима нужно использовать `web: python app.py webhook`)*

---

## Шаг 2: Деплой Python-бота из GitHub

Не выходя из вашего дашборда Railway:
1. Нажмите кнопку **"New Project"** (или **"+"** в правом верхнем углу).
2. Выберите **"Deploy from GitHub repo"** и выберите репозиторий с вашим ботом.
3. Railway тут же добавит карточку приложения и начнёт первоначальную сборку.
4. Скорее всего, сборка выдаст ошибку или бот просто упадет при старте, потому что **мы еще не задали переменные окружения** (токены). Это нормально.

---

## Шаг 3: Настройка переменных окружения (Environment Variables)

Бот не запустится без токена Telegram, API ключа DeepSeek и ссылки на вашу базу данных **Aiven**.

1. Нажмите на карточку вашего приложения (с кодом бота) в проекте Railway.
2. Перейдите на вкладку **"Variables"** (Переменные).
3. Здесь нужно построчно (или через кнопку **"Raw Editor"**) добавить все ключи из вашего `.env` файла.

**Что обязательно нужно добавить (Базовые настройки):**
- `TELEGRAM_BOT_TOKEN=ваш_токен`
- `SOURCE_CHANNEL_ID=-100...` *(исходный канал новостей)*
- `TARGET_CHANNEL_ID=-100...` *(куда публикуем)*
- `DEEPSEEK_API_KEY=ваш_api_ключ_deepseek`
- `ADMIN_USER_ID=ваш_телеграм_id`
- Все топики: `TARGET_MESSAGE_THREAD_ID`, `TOPIC_1_THREAD_ID`, `TOPIC_2_THREAD_ID` и т.д.

**Подключение Базы Данных (Aiven PostgreSQL):**
Так как ваша база данных находится не в Railway, а на платформе Aiven, вам нужно вставить строку подключения (Service URI), которую выдает Aiven:
- Создайте переменную `DATABASE_URL`
- Вставьте ссылку из панели Aiven, она выглядит примерно так:
  `postgresql://avnadmin:password@hostname.aivencloud.com:12345/defaultdb?sslmode=require`
*(Обязательно убедитесь, что в конце ссылки есть `?sslmode=require`, это жесткое требование Aiven)*

**Дополнительные настройки бота:**
Можете сразу задать настройки по умолчанию (позже их можно менять прямо через Телеграм-команду `/set_config`):
- `PUBLISH_SCHEDULE=8,12,16,20`
- `TEXT_LENGTH=medium`
- `ARTICLE_STYLE=informative`

Как только вы добавите все переменные, Railway **автоматически перезапустит** сборку вашего бота (redeploy).

---

## Шаг 4: Проверка логов и работы

1. Зайдите в карточку вашего приложения.
2. Откройте панель **"Logs"** (Логи).
3. Перейдите во вкладку **"Deploy" logs** — здесь показан процесс установки библиотек из `requirements.txt`.
4. Перейдите во вкладку **"App" logs** — здесь выводит логи само приложение Python (функция `logger`).

Если все настроено верно, в логах App вы увидите:
```
INFO - Connection pool к PostgreSQL успешно создан
INFO - База данных PostgreSQL инициализирована
INFO - Планировщик APScheduler запущен
INFO - Бот запущен. Мониторинг канала: -100XXXX...
```

Теперь бот полностью работает в фоновом режиме на сервере Railway!

## Рекомендации и советы по Railway

1. **Часовые пояса (Timezones):** 
   Серверы Railway работают в UTC. В коде бота (`timezone_utils.py` и `database.py`) уже заложена логика, которая всегда принудительно переводит время в Мадридское (`Europe/Madrid`). Поэтому расписание `8,12,16,20` будет срабатывать строго по испанскому времени!
2. **Лимиты (Free tier):**
   Если вы используете бесплатный тариф (Hobby), платформа даёт $5 или 500 часов работы в месяц. Python-бот почти не ест ресурсы системы, но бесплатный лимит по времени исчерпается примерно за 21 день непрерывной работы. Если планируете использовать для продакшена — перейдите на тариф "Developer". Так как бот очень легковесный (ему нужно около 60-100 МБ ОЗУ), стоимость его хостинга и хостинга базы данных суммарно составит копейки (около $1-2 в месяц).
3. **Обновления кода:**
   Как только вы исправите баг на компьютере и сделаете `git commit` + `git push` в ветку `main`, Railway автоматически перехватит этот код, остановит текущего бота и запустит обновленного бота (автоматический CI/CD). Ничего нажимать на сервере не придется!
