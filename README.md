# Telegram AutoPublish BOT with AI (DeepSeek) 🤖📰

Автоматизированная система для непрерывного мониторинга Telegram-каналов, умного парсинга статей, их перевода, стилистической обработки и автоматической публикации с помощью искусственного интеллекта (DeepSeek API).

## 🌟 Главные возможности

- **Автоматический мониторинг**: Отслеживание новых публикаций в исходном (Source) Telegram-канале в режиме реального времени.
- **Умный парсинг статей**: Автоматическое извлечение полезного текста новостей по ссылкам (с использованием `newspaper3k`) с отсечением лишнего мусора (комментарии, меню). Максимальный объем обрабатываемого текста ограничен **8000 символов** для экономии токенов API.
- **AI-обработка контента (DeepSeek)**:
  - **Перевод**: Автоматический перевод статей на русский язык.
  - **Стилизация**: Поддержка различных стилей написания (от нейтрального до саркастичного).
  - **Форматирование**: Создание структурированных постов для Telegram (с абзацами и жирным заголовком без лишней Markdown-разметки).
  - **Prompt Caching**: Улучшенная оптимизация запросов с использованием кэширования контекста на стороне API DeepSeek для минимизации расхода трафика и токенов.
- **Интеллектуальная категоризация**:
  - ИИ автоматически присваивает новости одну из 6 категорий (Налоги, ВНЖ, Жизнь, Испанский, Туризм, Семья) и добавляет соответствующие тематические хештеги (на русском и испанском языках).
  - Если категория не распознана, статья автоматически попадает в категорию `#life Жизнь и История`.
  - Новости автоматически публикуются в соответствующие подгруппы (топики) в целевом канале на основе присвоенной категории.
- **Умная очередь публикаций (APScheduler)**:
  - Планирование выхода постов по строгому расписанию (по умолчанию: 8:00, 12:00, 16:00, 20:00).
  - Выпуск **одной** новости за слот.
  - Поздние новости автоматически переносятся на утро следующего дня.
- **Детектор срочности "Молния" ⚡**:
  - Автоопределение срочных новостей по заданным ключевым словам (например, `молния`, `breaking`).
  - Срочные новости **игнорируют расписание** и публикуются моментально в главную категорию «Важные Новости и Налоги».
- **Продвинутое управление конфигурацией**:
  - Использование PostgreSQL (например, Aiven) для хранения настроек и очереди публикаций.
  - Изменение любых настроек "на лету" прямо через команды бота без перезапуска сервера.
- **Автоматическая очистка**: Умное удаление обработанных старых постов, которым больше 7 дней.

## 🏗 Архитектура и Техническая реализация (Как это работает)

### 1. Какие сервисы используются:
Бот является полностью автономным сервисом (backend-only), написанным на **Python 3.8+**. Для его работы используются следующие ключевые технологии:
- **PyTelegramBotAPI (`telebot`)** — Основной фреймворк для взаимодействия с Telegram API (прием сообщений, отправка постов в топики, обработка команд админа).
- **DeepSeek API (`deepseek-v4-flash`)** — Большая языковая модель (LLM), используемая для рерайта, перевода на русский, стилизации и определения категории статьи (Topic Classification). Выполняет роль умного редактора.
- **`newspaper3k`** — Python-библиотека для умного парсинга веб-страниц. Позволяет "вытягивать" только сам текст статьи и заголовок из URL-адреса, программно игнорируя меню сайта, рекламу и подвалы.
- **PostgreSQL (`psycopg2`)** — Основная база данных бота. Используется для хранения:
  - Очереди новостей (`news_queue`), их статусов (pending/published/failed) и расписания.
  - Динамической конфигурации (`bot_config`), позволяющей менять настройки бота (например, стиль написания) без перезагрузки процесса (на "горячую").
- **APScheduler** — Встроенный планировщик задач (cron-like). Отвечает за:
  - Публикацию готовых новостей из базы строго в назначенное время из `PUBLISH_SCHEDULE`.
  - Запуск ночной задачи очистки базы данных от старых новостей (+7 дней) в 3:00 ночи.
- **Flask** (Опционально) — Веб-сервер. Запускается исключительно в режиме "Webhook" для получения обновлений от Telegram напрямую (Push), в отличие от фонового опроса серверов (Polling).

### 2. Жизненный цикл новости (пошаговый алгоритм):
1. **Перехват (Telegram Handler):** Бот подписывается на канал-источник (Source Channel). Как только там выходит обычный пост со ссылкой на новостной ресурс, бот проверяет: свежий ли этот пост (вышел после старта бота).
2. **Извлечение (Regex & Парсинг):** Бот "выкусывает" URL-ссылку из текста. Библиотека `newspaper3k` переходит по этой ссылке, скачивает HTML-код страницы и извлекает из него "чистый" текст новости.
3. **Оптимизация трафика:** Извлеченный текст обрезается до максимум **8000 символов**. Это защита от "мусорных" страниц или бесконечных лент (чтобы не тратить токены DeepSeek впустую).
4. **Проверка на срочность:** Бот ищет в тексте триггеры из `URGENT_KEYWORDS` (например, "молния", "breaking"). Если находит — переводит новость в VIP-статус.
5. **AI Анализ (DeepSeek API):**
   - На сервер DeepSeek отправляется 2 блока: *System Prompt* (огромный кэшируемый блок с нашими правилами, стилем, лимитом символов и списком из 6 возможных категорий) и *User Prompt* (просто текст статьи).
   - DeepSeek анализирует текст, переводит его, применяет стиль (например, сарказм) и возвращает нам JSON-объект:
     `{"processed_text": "Готовый пост с нашими хештегами", "topic_id": 1}`
   - Если ИИ не смог понять категорию, он возвращает `topic_id: null`, и наш код принудительно ставит `topic_id = 3` (`#life Жизнь и История`).
6. **Очередь (PostgreSQL):** Готовый пост сохраняется в базу данных. Ему назначается `scheduled_time` (ближайшее свободное "окно" в расписании, например, 16:00).
   - *Особенность:* Если новость срочная (VIP-статус из шага 4) — она игнорирует базу данных и публикуется моментально в топик 1.
7. **Публикация (APScheduler):** Наступает 16:00. Планировщик "просыпается", лезет в БД, берет пост и смотрит на его `topic_id`.
   - Если `topic_id`: 2, бот отправляет его в Telegram-канал, строго в подгруппу `TOPIC_2_THREAD_ID`.
   - Пост помечается как `published`.

## 🛠 Требования для установки

- **Python 3.8+**
- **PostgreSQL** (локально или облачно, рекомендуется [Aiven](https://aiven.io/))
- **Telegram Bot Token** (выдается в [@BotFather](https://t.me/BotFather))
- **DeepSeek API Key** (создается на [платформе DeepSeek](https://platform.deepseek.com/))
- Права администратора в исходном и целевом Telegram-каналах.

## 🚀 Установка и Запуск

### 1. Подготовка окружения
```bash
git clone <repository-url>
cd TelegaAutoPublishNEWS
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
# venv\Scripts\activate   # Для Windows
pip install -r requirements.txt
```

### 2. Настройка конфигурации
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте файл `.env` и укажите ваши учетные данные.

**Ключевые переменные `.env`:**
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
SOURCE_CHANNEL_ID=-100123456789     # Откуда брать ссылки (ID или @username)
TARGET_CHANNEL_ID=-100987654321     # Куда публиковать

# ID подгрупп (топиков) для авто-маршрутизации (опционально)
TARGET_MESSAGE_THREAD_ID=           # Топик по умолчанию
TOPIC_1_THREAD_ID=                  # Топик: Важные Новости и Налоги
TOPIC_2_THREAD_ID=                  # Топик: ВНЖ и Амнистия
# ... и так далее до TOPIC_6_THREAD_ID

ADMIN_USER_ID=123456789             # Ваш Telegram ID для доступа к админ-командам

DEEPSEEK_API_KEY=your_deepseek_api_key
DATABASE_URL=postgresql://user:password@host:port/dbname?sslmode=require
```

### 3. Запуск бота
Система поддерживает два режима:

**Режим Polling (Разработка и небольшие проекты):**
Проще всего в настройке, не требует "белого" IP и сертификатов.
```bash
python app.py
```

**Режим Webhook (Продакшен):**
Самый быстрый и надежный способ для работы под высокой нагрузкой. Требует наличия домена с SSL (nginx/Apache).
```bash
python app.py webhook
```
*(Для работы Webhook не забудьте указать `FLASK_HOST`, `FLASK_PORT`, `WEBHOOK_URL` и `WEBHOOK_PATH` в файле `.env`)*

## ⌨️ Команды управления ботом

Отправлять команды нужно боту в **личные сообщения**.

### 👤 Публичные команды
- `/start` — Информация о состоянии бота и текущем расписании.
- `/help` — Вызов справки.
- `/status` — Статус очереди (сколько новостей ждет публикации, сколько опубликовано, ошибки).
- `/queue` — Вывод полного списка новостей, ожидающих публикации.
- `/get_style` — Узнать, в каком стиле сейчас ИИ пишет новости.

### 👑 Команды Администратора (требуют `ADMIN_USER_ID`)
**Публикации и Модерация:**
- `/publish_now <id>` — Немедленно опубликовать новость из очереди в обход расписания.
- `/clear_queue` — Полностью очистить очередь ожидания.
- `/view <id>` — Получить готовый текст статьи (предпросмотр) в личные сообщения без публикации в канал.
- `/rewrite <id>` — Заставить ИИ переписать статью заново (можно применить новый стиль).

**Управление настройками (изменение "на лету"):**
Все настройки (помимо базовых) сохраняются в PostgreSQL, поэтому они сразу применяются и не сбрасываются при рестарте:
- `/config` — Просмотр всех текущих настроек.
- `/set_config <ключ> <значение>` — Изменить настройку. Примеры:
  - `/set_config PUBLISH_SCHEDULE 9,14,19` *(Внимание: для расписания нужен перезапуск программы!)*
  - `/set_config TEXT_LENGTH short` *(short ~1000, medium ~2000, long ~3000 символов)*
  - `/set_config MAX_ARTICLES_PER_RUN 10`
- `/set_style <style>` — Изменить тональность текста: `informative` (стандартный), `ironic`, `cynical`, `playful`, `mocking`.

## 🧠 Специфика работы AI (DeepSeek)

### 1. Категоризация
Каждая новость автоматически прогоняется через ИИ для определения её топика и формирования хештегов. Бот маршрутизирует пост в соответствующую Telegram-подгруппу:
1. **#news** Важные Новости и Налоги — Официально: Законы из BOE, налоги (Modelo 100/721), банковские лимиты.
2. **#visa** ВНЖ и Амнистия 2026, Гражданство — Все виды Arraigo, Гражданство и инструкции.
3. **#life** Жизнь и История — Праздники, культура, интересные факты, история регионов. *(Сюда попадают новости по умолчанию, если ИИ не смог определить категорию)*.
4. **#spanish** Учим Испанский — Сленг, фразы для жизни, курсы и подготовка к экзаменам.
5. **#tourism** Туризм и Рестораны — Маршруты, лучшие тапас-бары, пляжи и планы на выходные.
6. **#family** Семья и Здоровье — Школы, садики, запись к врачам (SIP), пособия и страховки.
7. **#aboutus** 

К каждому посту ИИ генерирует двуязычные хештеги: русские и их дубликаты на испанском.

### 2. Оптимизация токенов (Prompt Caching)
Для минимизации затрат на использование API DeepSeek применяется строгая оптимизация отправляемых запросов:
- Зафиксированные правила форматирования, тональности, ограничения длины и структуры (а также список категорий) отправляются как системный промпт (System Prompt). DeepSeek кэширует данный объемный фрагмент текста на стороне сервера.
- Для запроса (User Prompt) используется только чистый текст статьи, который предварительно принудительно усекается до **8000 символов**. Это предотвращает "отравление" контекста большим объемом мусора в случае ошибок веб-парсинга и существенно бережет баланс API.

## 🛠 Устранение неполадок (Troubleshooting)

1. **Telegram: Conflict: can't use getUpdates method while webhook is active**
   - Вы пытаетесь запустить бота в режиме polling (локально), когда ранее к нему был привязан webhook. Бот пытается удалить вебхук автоматически на старте. Если не вышло, удалите его вручную:
   `curl https://api.telegram.org/bot<ВАШ_ТОКЕН>/deleteWebhook`
2. **Нейросеть отвечает ошибками / не может переписать текст**
   - Убедитесь, что у вас положительный баланс API в личном кабинете DeepSeek.
   - Проверьте, не блокирует ли исходный новостной сайт парсер `newspaper3k` (Cloudflare, защита от ботов).
3. **Изменения расписания `/set_config PUBLISH_SCHEDULE` не вступают в силу**
   - Это единственная настройка, требующая **перезагрузки** самого приложения (т.к. нужно пересоздать cron-задачи в APScheduler). Перезапустите сервер.
4. **Бот не отправляет сообщения в топики**
   - Убедитесь, что вы прописали корректные `TOPIC_1_THREAD_ID` ... `TOPIC_6_THREAD_ID` в файле `.env`. У топиков в Telegram используется числовой ID темы.
