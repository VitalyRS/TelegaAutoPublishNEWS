# Telegram AutoPublish BOT with AI (DeepSeek) 🤖📰

Автоматизированная система для непрерывного мониторинга Telegram-каналов, умного парсинга веб-статей, их перевода, стилистической обработки и автоматической публикации с помощью искусственного интеллекта (**DeepSeek API**). Поддерживает как полностью автоматический AI-рерайт новостей по ссылкам, так и публикацию готовых авторских дайджестов напрямую в обход нейросети (с тегом `#dai`).

---

## 🌟 Главные возможности

- **Автоматический мониторинг канала-источника**: Отслеживание новых публикаций в канале-источнике (`SOURCE_CHANNEL_ID`) в режиме реального времени.
- **Умный парсинг веб-статей**: Автоматическое извлечение полезного текста новостей по ссылкам (`newspaper3k`) с отсечением лишнего мусора (реклама, навигация, меню).
- **AI-обработка контента (DeepSeek API `deepseek-v4-flash` / `deepseek-v4-pro`)**:
  - **Перевод**: Перевод статей на русский язык с любого языка оригинала.
  - **Стилизация**: Поддержка тональностей (`informative`, `ironic`, `cynical`, `playful`, `mocking`).
  - **Сохранение ссылок**: Гарантированное сохранение ссылок на первоисточники в формате Markdown `[текст](url)`.
  - **Prompt Caching**: Оптимизация затрат на API за счёт кэширования системного контекста на серверах DeepSeek. Текст статьи предварительно ограничивается 8000 символами.
- **Интеллектуальная категоризация (7 категорий)**:
  - Автоматическая классификация новости и добавление двуязычных хештегов (русские + перевод на испанский).
  - Автоматическая маршрутизация поста в соответствующий топик (подгруппу) целевого форума/канала:
    1. **#news (cat1)** — Важные Новости и Налоги (BOE, налоги Modelo 100/721, банковские лимиты, жильё).
    2. **#visa (cat2)** — ВНЖ и Амнистия 2026, Гражданство (Arraigo, Regularización 2026, Digital Nomad, Citas/Huellas).
    3. **#life (cat3)** — Жизнь, Политика и Общество (Праздники, культура, региональные события, политика, курьёзы). *(Категория по умолчанию)*.
    4. **#spanish (cat4)** — Учим Испанский (Сленг, разговорные фразы, экзамены DELE/SIELE, грамматика).
    5. **#tourism (cat5)** — Туризм и Рестораны (Маршруты, тапас-бары, пляжи, отели, лайфхаки).
    6. **#family (cat6)** — Семья и Здоровье (Медицина SIP, страховки, школы, садики, детские пособия).
    7. **#about_us / #aboutus (cat7)** — Новости о нас и объявления администрации.
- **Прямые авторские посты и дайджесты (`#dai`)**:
  - Публикация готовых постов и подборок новостей в обход парсера и DeepSeek.
  - Полное сохранение ссылок на оригиналы `[текст](url)` с преобразованием в кликабельный Telegram HTML.
  - Автоматическая очистка редиректов Google (`google.com/url?...` ➔ прямой URL).
  - Автоматическое вырезание служебных тегов (`#dai`, `cat1`..`cat7`, `#aboutus`, `breaking`, `молния`) из текста публикации.
- **Умная очередь публикаций (APScheduler)**:
  - Публикация постов по расписанию (по умолчанию: 8:00, 12:00, 16:00, 20:00).
  - Публикация строго одной новости за слот.
  - Поздние новости автоматически переносятся на следующий день.
- **Детектор срочности "Молния" ⚡**:
  - Автоопределение срочных новостей по триггерам из `URGENT_KEYWORDS` (`breaking`, `молния`, `urgent`, `срочно`).
  - Срочные новости публикуются моментально в обход расписания.
- **Динамическая конфигурация (PostgreSQL)**:
  - Хранение настроек и очереди новостей в PostgreSQL.
  - Изменение любых настроек "на лету" прямо через команды бота без перезапуска сервиса.
- **Автоочистка БД**: Автоматическое удаление обработанных новостей старше 7 дней (каждую ночь в 3:00).

## 🏗 Архитектура и стек технологий

- **Python 3.8+**
- **pyTelegramBotAPI (`telebot`)** — взаимодействие с Telegram Bot API (webhook / polling).
- **DeepSeek API (`openai` SDK)** — генерация, стилизация, перевод и классификация.
- **newspaper3k + lxml** — извлечение чистого контента статей.
- **PostgreSQL (`psycopg2`)** — хранение очереди, истории и динамической конфигурации.
- **APScheduler** — планировщик публикаций и сервисных задач.
- **Flask** — легковесный веб-сервер для Webhook-режима.

## 🚀 Установка и запуск

### 1. Клонирование и установка зависимостей
```bash
git clone <repository-url>
cd TelegaAutoPublishNEWS
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

Пример конфигурации `.env`:
```env
# Telegram
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
SOURCE_CHANNEL_ID=@source_news_channel   # Откуда бот забирает новости
TARGET_CHANNEL_ID=@target_main_channel   # Куда публикует

# Топики форума Telegram (Thread ID)
TARGET_MESSAGE_THREAD_ID=                # Топик по умолчанию
TOPIC_1_THREAD_ID=101                    # Топик: Новости и Налоги (#news)
TOPIC_2_THREAD_ID=102                    # Топик: ВНЖ и Амнистия (#visa)
TOPIC_3_THREAD_ID=103                    # Топик: Жизнь и Общество (#life)
TOPIC_4_THREAD_ID=104                    # Топик: Испанский язык (#spanish)
TOPIC_5_THREAD_ID=105                    # Топик: Туризм (#tourism)
TOPIC_6_THREAD_ID=106                    # Топик: Семья (#family)
TOPIC_7_THREAD_ID=107                    # Топик: О нас (#about_us)

# Администратор
ADMIN_USER_ID=123456789                  # Telegram ID администратора

# DeepSeek
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
DEEPSEEK_MODEL=deepseek-v4-flash         # deepseek-v4-flash или deepseek-v4-pro

# База данных PostgreSQL
DATABASE_URL=postgresql://user:password@host:port/dbname?sslmode=require

# Webhook (для продакшена)
FLASK_HOST=0.0.0.0
FLASK_PORT=5000
WEBHOOK_URL=https://your-domain.com
WEBHOOK_PATH=/webhook
```

### 3. Запуск

**Режим Polling (локальная разработка / простые серверы):**
```bash
python app.py
```

**Режим Webhook (продакшен / Railway / облачный хостинг):**
```bash
python app.py webhook
```

## 📝 Руководство: Прямые посты и дайджесты (`#dai`)

Если вы хотите опубликовать авторский материал, подборку новостей или дайджест **без обработки искусственным интеллектом**, добавьте в текст сообщения в исходном канале тег `#dai`.

### Пример публикации с `#dai`:
```text
🤪 Испанский абсурд: Топ-5 самых забавных и курьезных новостей недели!

1. Спецоперация по поиску льва, который оказался пёсиком...
🔗 [Читать оригинал на 20minutos.es](https://www.20minutos.es/article.html)

2. Пиратский флаг как навигатор для голубей...
🔗 [Читать оригинал на elnortedecastilla.es](https://www.elnortedecastilla.es/article.html)

#Испания #Курьезы #Юмор cat3 breaking #dai
```

### Что сделает бот:
1. Распознает `#dai` и отправит пост в очередь в обход парсера и нейросети.
2. Автоматически определит срочность (`breaking` ➔ публикация сразу) и тему (`cat3` ➔ топик #life).
3. **Очистит служебные слова**: вырежет `#dai`, `cat3`, `breaking`, оставив только `#Испания #Курьезы #Юмор`.
4. Сохранит все кликабельные ссылки на оригиналы в формате HTML.
5. Очистит любые редиректы Google, если ссылки скопированы из поисковика.

## ⌨️ Команды управления ботом (в ЛС боту)

### 👥 Основные команды
- `/start` — Информация о состоянии бота, времени запуска и расписании.
- `/status` — Статистика очереди (в ожидании, опубликовано, ошибки, срочные).
- `/queue` — Список новостей в очереди ожидания со временем публикации.
- `/help` — Подробная справка по всем командам и возможностям.
- `/get_style` — Показать текущий стиль написания новостей.

### 👑 Команды Администратора (требуют `ADMIN_USER_ID`)

**Модерация и публикации:**
- `/view <id>` — Предпросмотр отформатированного текста новости из очереди.
- `/rewrite <id> [style] [length]` — Переписать новость через DeepSeek с новым стилем/длиной.
- `/publishnow <id>` — Опубликовать новость немедленно в обход очереди.
- `/clear_queue` — Полная очистка очереди публикаций.

**Управление конфигурацией "на лету":**
- `/settings` — Интерактивное кнопочное меню настроек.
- `/config` — Просмотр всех текущих настроек из БД.
- `/set_config <ключ> <значение>` — Изменить настройку в БД без перезапуска.
  - `/set_config TEXT_LENGTH short` (`short` ~1000, `medium` ~2000, `long` ~3000 символов)
  - `/set_config MAX_ARTICLES_PER_RUN 10`
  - `/set_config URGENT_KEYWORDS молния,breaking,urgent`
  - `/set_config PUBLISH_SCHEDULE 8,12,16,20` *(для расписания требуется перезапуск планировщика)*
- `/set_style <style>` — Изменить стиль: `informative`, `ironic`, `cynical`, `playful`, `mocking`.
- `/reload_config` — Принудительно перечитать настройки из базы данных.
